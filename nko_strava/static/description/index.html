Fitness Sync: Strava & WHOOP

Your training, recovery and sleep in Odoo, next to everything else you track.

What it syncs

  • Strava activities: your full history, including sport, distance, moving/elapsed time, pace or speed, elevation, heart rate, power, calories, kudos, PRs, gear and device. Shown in miles/feet with pace per mile for runs and mph for rides; raw metric values are kept too.
  • Route maps: every activity with GPS shows its route on an OpenStreetMap map with start and finish markers. A Map menu shows all your routes at once, filterable by sport and year.
  • Strava totals: last 4 weeks, year to date and all time for run, ride and swim.
  • WHOOP: recovery (score, HRV, resting heart rate, SpO2, skin temperature), sleep (performance, efficiency, stages, respiratory rate), daily strain and workouts. Recovery is color-coded green / yellow / red.
  • List, calendar, graph and pivot views for everything, e.g. distance by month and sport, or HRV over time.

Setup (about 2 minutes)

  1. Strava: at strava.com/settings/api, create an API application and set the Authorization Callback Domain to your Odoo domain (shown in the app's settings).
  2. WHOOP: at developer-dashboard.whoop.com, create an app with the read scopes plus offline, and add the Redirect URI shown in the app's settings.
  3. In Odoo, open Fitness Sync → Configuration → Settings, paste each Client ID and Client Secret, and save.
  4. Click Connect Strava and Connect WHOOP and approve. The first sync starts right away; after that, data syncs every hour, or on demand with Sync Now.

Built to keep your connection alive

WHOOP invalidates the previous refresh token every time a new one is issued. This module refreshes tokens only when they have actually expired, saves a new token before using it (so a failed sync can't lose it), and lets only one process refresh at a time. If a provider rejects the connection, it is marked Reconnect needed instead of retrying in a loop.

Notes

  • Requires the Python requests library (included with Odoo).
  • Client secrets and tokens are visible to Settings administrators only.
  • Map tiles are loaded from OpenStreetMap; the Leaflet library is bundled with the module.
